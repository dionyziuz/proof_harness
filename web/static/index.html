The Prime Math Agent Framework

Autonomous multi-agent mathematical reasoning harness designed for theoretical research.

Unlike general-purpose conversational LLMs that hallucinate inductive leaps, Prime Math executes a disciplined, multi-turn cognitive cycle governed by formal guardrails:

1. Context Architect

Analyzes theorem preconditions, extracts invariants, maps combinatorial constraints, and isolates verified definitions.

2. AST-Scanned REPL Kernel

Executes SymPy, Z3, and NetworkX computations in a secure isolated environment. AST inspection blocks unverified assumptions.

3. Academic Proof Auditor

Independent adversarial referee subagent that scores validity, rigor, and boundary conditions. Flags structural gaps with surgical precision.

4. Golden Balance Pivot Gate

Protects improving drafts on single strikes while immediately executing clean-slate hard pivots on confirmed dead ends.

5. Publication Scribe Subagent

An isolated synthesis subagent that receives the verified claim ledger and typesets a self-contained, journal-grade LaTeX proof.
